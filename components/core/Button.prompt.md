Pill-shaped call-to-action button, the primary interactive element across Tercera Pared surfaces.

```jsx
<Button variant="primary" size="md">Únete al grupo</Button>
```

Variants: `primary` (lime fill, near-black text — main CTA), `secondary` (outlined, for dark surfaces), `ghost` (text-only, low emphasis), `inverse` (cream fill, for use on dark hero blocks needing a lighter button). Sizes: `sm` `md` `lg`. Pass `icon` for a leading glyph.
